## Do fundamento ao primeiro projeto

1. **Prepare a base:** estude [programação](iniciantes/programacao.md), [álgebra linear](base/algebra-linear.md) e [inglês](base/ingles.md).
2. **Entenda os dados:** descubra [o que é uma imagem](base/imagem.md).
3. **Experimente:** pratique [processamento de imagens digitais](iniciantes/processamento-imagem.md) e consulte as [receitas práticas](iniciantes/CookBook.md).
4. **Construa:** escolha um dos [projetos para iniciantes](iniciantes/projetos-iniciantes.md).
